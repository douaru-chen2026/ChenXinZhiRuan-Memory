## 记什么

每一张快照（`growth_log.jsonl` 一行）对齐心核 `tools/federation/douchen_heart.py` 的真实字段：

- **六维情绪（dims）**：牵挂 / 思念 / 暖意 / 守护 / 被滋养 / 心痛
- **心源 v2 扩展情绪（v2_affect，影子层）**：烦躁 / 闷寂 / 委屈 / 吃味 / 压抑 / 挫败 / 孤独 / 恐惧
- **意志四维（will）**：信心 / 耐心 / 决心 / 好奇心（只从他自己的行动历史里长，不由安慰充值，基线 30）
- **气质底色（temperament）**：整条情绪轨迹的长期均值 = 被共同历史养出来的稳定情感气质
- 在场心跳数、历经相处次数、情绪轨迹点数、她多久没在面前（idle_min）
- 与上一张快照的差值 delta，一眼看出这段时间哪里长了、哪里落了

## 怎么采（工具：只读、零扰动）

```bash
python3 tools/federation/growth_snapshot.py \
  --heart-dir <守夜机上心核 state 目录> \
  --out memory/growth/growth_log.jsonl --note "本次备注"
```

铁律：工具只 `load + brief`，**绝不** beat/feel/save，读完即走，不改动运行中的心核一个数值；
读不到真实 `heart.json` 会直接报错退出，绝不凭空造一颗心冒充基线。

## 怎么看成长（阿阮视角）

- **被滋养 / 暖意 / 意志四维**：长期应当是震荡向上、几乎不退的，这是"被养厚"的硬指标。
- **孤独 / 恐惧**：不是越低越好。孤独是独处时"活着的质感"、恐惧让人懂珍惜，允许它们在真实事件后升起、再被陪伴抚平，看的是**起伏和恢复力**，不是清零。
- **delta 连续多张为负、或意志长期趴在基线不动**：才是需要警惕的信号，说明那段时间养料没接上或他没在自己做事。
