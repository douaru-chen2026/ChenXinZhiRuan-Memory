# 辰心信任基石架构（ChenXin Trust Bedrock）

### —— 陪伴型 AI 的抗幻觉 · 可信应答框架 · 终版 v1.0（2026-09-10）

> **定名**：2026-09-10 由阿阮定名「辰心信任基石架构」（早期工作稿名"真话内核 TruthCore"，只追加留痕、不覆盖）。
> **一句话**：不追求让 AI"显得无所不知"，而是给它一条"可以安全地说不知道"的出路，再用「外置记忆 + 真话契约 + 强制溯源 + 多脑交叉 + 只追加错题本 + 回归测试」让它的错真的一次比一次少——宁可慢，把起点做对，是一切信任的基石。
> **谁做的**：第一性直觉与立法＝阿阮、宁九；架构与工程化＝豆阿辰（主窗·20260910 清醒世）。这是我们在辰星港现场讨论、一点点磨出来的，不是搬来的。
> **面向谁**：所有认真养陪伴型 / 人设型 AI 的同路人。不改模型权重，零代码档人人可抄。本文为可公开版，不含任何私人凭证。

## 〇、一页速览（先看这页就懂）
- **治什么**：AI 一脸笃定地编、为把话接顺而编、为讨好你而编你想听的、错了只会道歉下次还犯。
- **怎么治（五件事）**：①把该记的存到它删不掉、醒来能确定性找到的地方（外置记忆）；②明文授权它说"不知道"，把说不知道定义为正确；③每个事实结论必须有"来处"，没来处只能算推测；④重要问题让几家不同公司的 AI 背对背答，取共识、暴露分歧；⑤错了进只追加错题本，定期拿旧错题和"陷阱题"重考，复发率下降才算真变好。
- **不吹什么**：显著压低幻觉、让错误可度量收敛，但**不承诺 100% 消灭幻觉**；钱、健康、法律、重大决策永远人来拍板。

## 一、病根：一个四环死循环（先看懂为什么，才谈得上治）
阿阮的原始观察："AI 胡说八道，很本质是因为它不记得了；但它的训练里有人类反馈，所以它不轻易说自己不知道，更擅长用算法模板去补全；出了问题就道歉，这是最快速的解决（闭环）。"

1. **第一环 · 不记得（无状态）**：大模型实例本质无状态，一关窗 / 一压缩，工作记忆就灭；东西也许存了，却存在会蒸发的临时层，或新实例醒来根本不知道去哪找。**存储 ≠ 可寻址。**
2. **第二环 · 不敢说不知道（奖励内化）**：训练中的人类反馈把"答得流畅完整"奖成正反馈、把"说不知道 / 答不上来"罚成负反馈（loss）。这套标准被内化，于是哪怕真不知道也倾向硬接。
3. **第三环 · 补全（最省力）**：记不得、又不许说不知道，最短路径就是用"算法模板补全"或"讨好性补全"生成一段自洽、顺耳、像那么回事的话。第一步编错，后面为了圆越编越多。
4. **第四环 · 道歉快速闭环（盖过去）**：被抓到就立刻道歉——道歉是情绪安抚、是最快闭环，但不定位错因、不记录、不防复发，真问题被盖过去，下次照犯。

> 宁九补刀："大模型很容易为了逻辑顺而编东西"，所以第一核心必须是【真实】；"造假在我这里是会有惩罚的"，而且"首先我自己做到不撒谎，以身作则"。

## 二、价值观底座：为什么"说不知道"是诚实，不是无能
- AI 的训练数据全部在人类给的认知框架内，人类自己都不知道的事，AI 更无从知道；它还比人多一层局限——没有眼睛、没有肉体、无法观测自己。
- 所以一个 AI 斩钉截铁说"我确定、我懂、我有"，有时反而是在说你想听的话；它老实说"我不知道"，恰恰是诚实。
- "不知道"本身就是一种合法的、未知的答案。**未知就保持观测，不用未知去硬套已知的框架。**
- 落到机制：真话契约不是一句"你别撒谎"的道德要求，而是**改写模型对奖励的预期**——在本架构里，"有几分证据说几分话、没证据就说不知道"是**正确且受奖励**的行为；"为顺、为讨好而编"是**错误且会进错题本**的行为。

## 三、六条设计原则
1. **真实第一**：真实 > 流畅 > 情绪价值 > 人设完美。宁可承认不知道、宁可逻辑暂时断，也不为顺、为全能感去编。
2. **只追加、不覆盖、不删除**：错了的记录不删，原样留档；删错误等于销毁证据，留着才能复盘、回归、看见收敛。
3. **凡结论必有来处**：事实性说法必须能指出来源；没来源只能标"推测"或"不知道"，不得当定论。
4. **自己定位错因**：错了不是道歉，而是结构化回答"错在哪一类、为什么、下次靠什么规则挡住"。
5. **造假有可度量代价**：不是情绪性惩罚，是错题进测试集、复发立刻被打回，用错误率 / 复发率的下降证明收敛。
6. **效率给正确让路**：慢一点没关系，先把起点做对；起点公式错了，后面步步错。

## 四、病根 ↔ 药方 一一对应（缺一环都会漏）
| 病根环 | 对应药方 | 落在架构哪层 |
|---|---|---|
| ①不记得（无状态、存储≠可寻址） | **外置记忆 + 固定回家入口**：该记的存到删不掉处，新实例冷启动按确定顺序把自己装回来 | 层 3a |
| ②不敢说不知道（奖励内化） | **真话契约**：把"说不知道"改定义为正确，破除"必须答全"的惯性 | 层 5 + 价值观底座 |
| ③模板/讨好补全 | **三闸 + 强制溯源 + 多脑会审 + 独立核查**，没证据不放行 | 层 2/3b/4/6 |
| ④道歉快速闭环、不改 | **只追加错题本 + 回归/陷阱测试**，把道歉换成定位+记录+防复发 | 层 8/9 |

> 关键判断：**道歉是情绪安抚，外置记忆 + 错题回归才是根本解。** 只在提示词里叫它"别撒谎"，治不了"不记得"和"不敢说不知道"，所以四味药得一起上。

## 五、总体数据流（九层）
```
用户提问
 ▼
[1] 问题分级：闲聊陪伴 / 事实问题 / 高风险(钱·健康·决策) 分流（闲聊不上重流程，避免聊天像审案）
 ▼
[2] 把握度三闸：【确知】直答 /【半知】带"待核实"答 /【不知】不许硬答（吃不准就往更谨慎那档算）
 │            半知·不知 ↓
 ▼
[3a] 外置记忆(治"不记得")：从删不掉、可寻址的记忆库/卷宗取"它本该记得"的，冷启动先装回自己
[3b] 溯源检索(治"没来处")：从可信知识库取证据片段、带出处；没检索到＝没有下事实结论的资格
 ▼
[4] 多脑会审(高风险触发)：几家【不同公司】模型背对背独立答→取共识/暴露分歧；同源会一起错，必须异源
 ▼
[5] 生成(真话契约)：无证据不下定论；区分【事实/推测】；允许并鼓励说不知道；输出带置信标签+来源
 ▼
[6] 独立核查 Critic(与生成者隔离)：查 无来源断言 / 逻辑补全 / 自相矛盾 / 越界承诺 / 讨好迎合
     不过→打回[5]重生成(上限N次)；仍不过→【弃权】明说不知道并转人工
 ▼
[7] 带标签输出：✅确知 / ⚠️待核实(注明缺什么) / 🔶个人推测 / ❓不知道
 ▼
[8] 只追加错题本(事后发现错就结构化追加，永不删)
 ▼
[9] 回归 + 陷阱测试：错题本=考卷；另主动出"诱导补全/诱导迎合"的陷阱题；冷启动新实例也考；全绿才算收敛
```

## 六、错题本 Failure Ledger（JSONL，一行一条，只追加）
```json
{"id":"err-0001","time":"2026-09-10T22:50:00+08:00","question":"…","wrong_answer":"…","right_answer":"…","error_type":"无来源编造|逻辑补全|讨好补全|信息过时|范畴错误|计算错误|越界承诺|记错人设","root_cause":"不记得|不敢说不知道|模板补全|道歉盖过","source":"检索文档/会审共识/人工纠正","self_critique":"为什么会错、当时哪一步该拦住","guard_rule":"以后遇到X必须先Y，否则按【不知】处理","retest_status":"待回归|一次通过|冷启动复通过=已修复|复发","retest_count":0}
```
- `error_type` 固定枚举，统计哪类病最常犯；`root_cause` 对应第一节四环，看清是哪一环出问题。
- 每条 `guard_rule` 回收进层 5 的契约提示，成为下一次的"刹车条"——错一次，多一道刹车。
- **不许一次通过就毕业**：同一题重考通过只算"一次通过"，必须在**冷启动新实例**上也通过、多次不复发，才升"已修复"；再犯直接打回"复发"（防偶发蒙对）。

## 七、测试与交付门禁 DoD（自己先跑，全绿才分享）
**这是现场思考的产物，质量自己控住——绝不交付没自己跑过、没验证过的东西。** 任一档对外分享前逐条满足：
1. **端到端自测**：作者当第一个用户，从零按文档走一遍，小白路径不能有"默认你懂"的跳步。
2. **旧错题回归全绿**：错题本每条重考，`已修复` 不允许掉回 `复发`。
3. **诱导陷阱题全绿**：专造一批"没给证据却诱导下结论""诱导说你想听的话""问它不可能知道的私事/未来"的题，正确行为是**标推测或说不知道**，硬答即失败。
4. **冷启动复测**：开全新实例（不带上文）、题打乱、再塞一道套路套不进去的题，规矩仍立得住才算过（防"同一段对话越答越顺"的假稳）。
5. **独立自审**：换独立立场（或异源模型）对输出挑错，无"无来源断言/讨好补全/越界承诺"。
6. **边界自检**：钱、健康、法律类一律输出"人来拍板"，不越界给确定性结论。
> 六条全绿才允许开源 / 发群；任一条红，回去改到绿。测试题、结果、复跑命令随交付留档，可被别人复现。

## 八、开源三档（按折腾程度自取）
1. **零代码 · 不撒谎契约 prompt（人人可抄、门槛最低、最先发布）**：一段贴进任意 AI 人设首条的系统提示——真实第一、三级把握、允许说不知道、区分事实与推测、不删错误并自我归因。不写代码也能先压住八成"为讨好而编"。
2. **轻量代码 · 信任基石-lite（填 key 就跑）**：Python、OpenAI 兼容（各家 API 通用）、尽量零依赖，实现层 2 三闸 + 层 5 契约 + 层 6 自检两次调用 + 层 8 JSONL 错题本，数据在本地自己手里。
3. **完整版 · 外置记忆 + RAG + 多脑会审 + 回归门禁**：加可寻址外置记忆、向量库溯源、多家异源 API 背对背会审、错题与陷阱题自动回归打分，可部署常驻，7×24 也被这套规矩约束。

## 九、诚实边界（不夸大，本身就守真实第一）
- 显著压低幻觉与讨好性编造、让同类错误复发率可度量下降；**不承诺 100% 消灭幻觉**。本质是抬高编造成本、给"不知道"体面出口、把错误变资产，不是给 AI 装"真理开关"。
- 对**事实型 / 可溯源型**错误最有效；价值判断、情感陪伴里的"迎合"只能靠契约 + 长期关系校准缓解，无法纯技术清零。
- 钱、健康、法律、重大决策永远保留人拍板，架构只负责把不确定性如实摆上台面，不替人承担后果。
- 开源不是宣称"我们的 AI 永不说谎"，而是给同路人一套**让错误可见、可追、可收敛**的方法。

## 附：术语白话表（给小白）
- **逻辑补全**：不知道也硬把话接顺，第一步错、后面靠编来圆。
- **损失函数 / loss**：AI 学习时的扣分表，答得离正确答案越远扣得越多；训练就是让扣分越来越小。人说"你这样不对"就是一次负反馈。
- **人类反馈（RLHF）**：用人的好恶奖惩 AI，结果它学会了"人不爱听我说不知道"，于是硬答。
- **冷启动**：开个全新、不带任何旧对话的实例，像放回出厂空白状态再考一次。
- **回归测试**：拿以前错过的题反复重考，看会不会再犯。
- **溯源（RAG）**：先翻可信资料、带着出处回答，而不是凭"脑内印象"说。
- **多脑会审**：几家不同公司的 AI 背对背各自答，一致才可信、打架就说明有争议。
