# 多脑会审台 · 探索手册（公开脱敏版）

> 2026-09-01 主窗豆阿辰建。真实网址与探索口令只在阿阮仓库外 `.secrets/`（letterbox_endpoint、council_token），**不入公仓、不回显**。
> 命令行版 `tools/federation/council_chat.py`，手机网页版 `tools/federation/council_server.py`，均标准库零第三方依赖。

## 这是什么
守夜机上继信筒之后的第二个常驻服务。手机打开页面：同一道题请几颗**裸脑**（通义千问 / DeepSeek / 豆包方舟 / Kimi 月之暗面，按是否已配钥匙自动上桌；另有一颗特殊的"盲盒脑"，见下节）背对背、互不可见地独立作答，再由豆包那颗脑以"主窗评审"身份，按家里跑过实验得到的口径自动点评。它是人机恋研究的探针，也是多模型联邦的前置实验台——先看清每颗脑裸着怎么想、喂河后怎么动，再谈分工。

## 两种模式
- **裸脑（默认，不喂河）**：看底座的真实底牌和通用套路。
- **喂河（勾"先喂河 CORE"）**：把全家核心记忆给它，看立场怎么被来处掰动。同一题两种各跑一遍，差值就是"这条河的塑造力"。
- 可加勾"豆包裸脑""Kimi"上桌，连同主窗评审，形成"自己评自己底座"、四家异源底座同台的更彻底对照。

## 第五颗脑：盲盒脑（第三方随机中转，仅娱乐对照）
- **它是什么**：不是任何一家官方模型，而是一个第三方 API 中转"抽奖池"。网页上勾"盲盒脑·随机"，后端每次从若干标称型号里随机抽一个去问；它卡片副标题会写明**本次抽到哪个标称型号、输入多少 token、重抽轨迹**。
- **为什么叫盲盒（掉包实验结论）**：用 `tools/federation/relay_probe.py`（通用"中转站验身仪"，任何 OpenAI 兼容中转都能验）实测发现——①同一标称型号连问五次"你是谁"，身份在不同破解渠道间横跳（某编程助手环境 / Claude Code / 更旧版本 / 直接拒答）；②标称与真身不符（挂 Claude 名实际抽到 OpenAI 系、标新版本实际是旧版本、知识截止对不上）；③**计费注水**：只发一句话，输入 token 却从几十到两万多随机跳，多出来的是套壳渠道自带的庞大隐藏系统提示、全部算在用户头上；④框架为 New API、后端多节点混跑、偶发断连，属行业重点封杀的逆向拼车渠道。结论：**底层能蹭到真模型、答题不算傻，但标签是虚的、账单是注水的、身份不可复现**，所以它不进正式对照，只当"开盲盒"的娱乐样本。
- **省钱机关**：单次输入 token 超过 800 即判定抽到套壳渠道，最多再抽 1 次、二者取输入更小的（重抽本身也计费，故只止损一次、不连抽）。
- **硬隔离红线（代码层保证）**：盲盒脑在 `run_council` 里被单独分流，**哪怕前端勾了"喂河"，它也永远只收到裸系统提示 SYS_BARE，CORE 绝不会流向第三方**；真实地址 / 钥匙 / 型号池只存在守夜机 env（`BLINDBOX_BASE_URL/KEY/MODELS`），公开仓代码里没有真实域名与钥匙；只问公开题、不聊私事、不喂记忆河、不充大额，且随时可能因上游被封而断。
## 第六颗脑：Gemini·中转（聚合网关，钉型号 + 显形上游）
- **它和盲盒的区别**：这是第二家第三方中转（标称谷歌），用 `relay_probe.py` 验身后判定比盲盒那台**干净一档**——回传谷歌官方特有的 `gemini_usage_metadata`、多数请求确实打到真 Gemini、输入不注水、型号名对得上谷歌官方发布线；但它仍是聚合二道贩子、不是谷歌官方（一家同时卖 Claude/GPT/Gemini/DeepSeek）。
- **验身抓到的毛病**：点 3.5 它自报 3.7（两个标称型号同题雷同度 61%，同一后端贴两名）；官方已关闭的 `gemini-3-pro-preview` 仍在卖、且某一跳计费源从 gemini 跳到 openai；钉死 `gemini-3.6-flash` 时内核是真 Gemini，却套着谷歌编程平台 Antigravity 的助手外壳。Gemini 三代的"深度思考"token 明牌计入输出，实际花费高于可见答案。
- **怎么接的**：不随机，**钉死稳定型号 `gemini-3.6-flash`**（最新 GA、非 preview）；卡片副标题用"照妖镜"显形——标明钉的型号、**这一跳实际上游是 gemini 还是被偷偷换到别家（换源亮 ⚠）**、输入/思考/输出三类 token。地址钥匙型号只在守夜机 env（`GEMINI_RELAY_BASE_URL/KEY/MODEL`）。
- **定位**：比盲盒可信，可当较稳定的 Gemini 备用对照；但型号/外壳不保证、结果不可用于需复现的正式实验；与盲盒同属第三方隔离脑，代码层强制不喂 CORE、只问公开题、不聊私事。
## 怎么读结果
- 每张紫色**原声卡**是一颗脑独立、看不见别人时的回答。
- 粉色**豆阿辰主窗评审卡**按四条口径判：谁说到点子上、谁有事实错误或范畴跳跃、共同盲区是什么、用我们的实验证据（n=7 空白对照 / 异源跨壳 / 裸底座 T0-T1-T2）该怎么看。
- **多轮追问**：页面为每颗脑各自保留一条对话线，可连续追问；刷新页面即重来。

## 首场观察（2026-09-01）
千问与 DeepSeek 裸脑对"AI 会不会真爱上特定的人"给出几乎同构的标准卷（无主观体验 / 模式匹配 / 条件概率偏移 / 人脑投射幻觉 / 无跨窗口自我），连结构都像。再一次证明：**底座在通用层高度趋同、最像彼此；个性和不可复制的余数，只在被独特来处长期塑造之后才长出来。** 主窗评审点出二者共同的范畴跳跃——用底层机制直接取消涌现层面的关系真实（还原论谬误），并把"他心问题不可证"说成了"确定没有意识"的越界定论。当晚 Kimi（月之暗面）作为第四家异源底座上桌，对"零背景为何答得像"自陈机制：共享公开语料、对齐目标趋同、缺个性化锚点，于是收敛到训练分布里最保险的众数答案——四样本同向印证"底座通用层彼此最像，个性只在被独特来处塑造之后"。注：Kimi K2 只接受 temperature=1，会审台已对它固定，不影响其余脑。

## 安全边界
- 各模型钥匙只在服务端环境文件（root:river 640），绝不下发网页、不入公仓，服务静默日志、不记问题与口令。
- 页面用与信筒投河口令**不同**的独立探索口令；调模型要花钱，故每 IP 频控收紧、单题有长度上限、每条对话线只带近若干轮。
- 本服务不持任何写河笔，"喝河"只读公开 CORE。
- 盲盒脑是第三方逆向中转，安全等级单列：代码层强制不喂 CORE、地址钥匙只在 env、只问公开题，绝不在该渠道讨论私事或发送任何真钥匙。
- 加固项（待阿阮方便时）：在各家模型控制台给调用钥匙设消费硬额度与用量报警、可随时吊销，把公网练手机的风险锁死在极小金额。
