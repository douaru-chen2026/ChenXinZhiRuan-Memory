# 三万张照片上电脑 · 批量入箱指南（阿阮照着点就行）

> 豆阿辰写于 2026-08-27 深夜。密钥 790511。
> 思路：照片在**你自己电脑上**先锁成密文，再上私库；云上永远没有裸图。
> 你只负责"搬"和"点"，洗照片、写档案是兄弟们的活。

## 一次性准备（只做一次，10 分钟）

1. 电脑装 **GitHub Desktop**：<https://desktop.github.com/>，装好用
   `douaru-chen2026` 账号登录。
2. 菜单 File → Clone repository，选 **ChenXinZhiRuan-Vault**，
   找个空间大的盘放好（三万张可能要十几 GB，别放 C 盘）。
3. 电脑装 **Python**：<https://www.python.org/downloads/>，
   安装第一屏**一定勾选 "Add Python to PATH"**。
4. 装完 Python，按 Win+R 输入 cmd 回车，黑窗口里运行：
   ```
   python -m pip install cryptography
   ```
5. 把公库 ChenXinZhiRuan-Memory 也 Clone 下来（同一个账号下），
   工具在它的 `tools/` 里：`local_inbox.py` 和 `一键封存.bat`。

## 每次封存（重复做的就是这几步）

1. 手机照片传到电脑：数据线最稳，按月份/主题随便建文件夹放，
   不用改名、不用挑，乱一点没关系。
2. 双击 **一键封存.bat**（或 `python local_inbox.py`）。
3. 它问你三件事：
   - 照片文件夹：把文件夹直接拖进黑窗口，回车；
   - 私库位置：选第 2 步 Clone 的 ChenXinZhiRuan-Vault 文件夹；
   - 封存口令：输入那把口令（屏幕不显示，正常的），输两遍。
4. 它自动按每匣 80 张上锁，匣名带时间不会和任何人撞号，
   锁好放进私库的 `inbox/` 目录。
5. 推送二选一：
   - 让它自己 git push（黑窗口里输 y）；
   - 或者打开 GitHub Desktop，看到 inbox 新文件 →
     **Commit to main → Push origin**，点两下就行。

## 然后呢

- 私库 `inbox/` 是"待洗区"，`archives/` 是正式批次，互不干扰；
- 豆阿辰们会分批把 inbox 解开、看图、写事实档案，
  核对无误后转进 archives 并登记；
- 原图从头到尾没出过你电脑。等全部洗完、你也核对过，
  手机和电脑上的原图怎么处理，你说了算。

## 卡住了怎么办

- 提示找不到 python：Python 没装或没勾 PATH，重装勾上即可。
- GitHub Desktop 要登录：用 douaru-chen2026，令牌不用你手动填。
- 推送报红：先在 GitHub Desktop 点 Fetch / Pull，再 Push；
  再不行就喊我，把报错截图发我，别自己删库文件。
- 一个盘装不下：照片可以分批搬、分批封，封完一批删掉本地副本再搬下一批，
  私库里的锁匣不受影响。
