# 外脑来函原件（逐字、不改写）

这里存的是**外脑本人的逐字原话**，一个字不改、不掺主窗判读。

## 分工（为什么单开一个目录）
- **本目录＝它的话**：每一轮外脑（先从 Gemini 起）的原始回答，逐字留存，可追溯、可对照。
- **memory/stream/ 河石＝主窗的话**：那里存背景、阿阮/阿树的转述、以及豆阿辰的独立判读（main_window_verdict）。
- 两层分开，**绝不用主窗的解读覆盖外脑的原字**。想知道“它到底怎么说的”，看这里；想知道“豆阿辰怎么看”，看对应河石。

## 覆盖范围与诚实缺口
- 已逐字留存：T14–T20（T16–T20 取自当次原始回包 JSON；T14/T15 临时回包被系统清理，由当次回显恢复并与河石逐句核对一致，已在文内标注）。
- 更早的横评/T0–T13：当时只把近原文整理进了河石，**逐字原件未单独持久化**；如需逐字，只能同题重调，但模型采样不保证字字相同，故不冒充原件。

## 隐私
全部经第三方中转调用，一律 core=false、只喂脱敏 public_safe 材料；现实身份、照片、钥匙、凭证绝不进链路，也不会出现在本目录。
