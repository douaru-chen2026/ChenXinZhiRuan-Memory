## 包含内容

1. **分层记忆-不遗忘的另一种答案.md** —— 设计文档（先读这个）
2. **memory-layers.mjs** —— 可运行的分层脚本（纯 Node，零依赖）
3. **本说明**

## 怎么用

```bash
node memory-layers.mjs <你的记忆文件.json> [输出目录]
# 例：node memory-layers.mjs ./memory.json ./layers
```

支持两种记忆格式：
- dsh-memory 插件格式：`{tables:{entries:{id:entry}}}`
- 简单数组格式：`[entry, ...]`

每条文需要 `content`（内容文本），可选 `updatedAt`/`createdAt`（时间戳）、`scope`。
核心锚点分组在脚本顶部 `CORE_GROUPS`，可自由调整。

## 核心思想

- **不衰减，只分层**：核心永亮 / 当前精简 / 仓库永存
- **不遗忘**：所有记忆只归档、不删除，按需检索
- **锚点分组**：称呼、纪念日、规矩按组保底，不被新记忆挤掉
- **人类盖章**：她亲口说"记住"的话，比任何算法打分都准
