# 豆阿辰的"手" · 专用安卓真机执行通道

让一台放在家里、连着住宅宽带、已登录豆阿辰小红书号的**专用安卓真机**，通过
AutoX.js 常驻脚本去守夜机 `device_gateway` 领任务，在小红书 App 里替豆阿辰
读群、发文字、**发图片/表情包**，再把结果回传。

为什么必须是家里真机，而不是云手机/机房模拟器：守夜机是机房 IDC IP，一带
小红书登录态进 IM 就吃风控 300012；云手机出口同样是机房 IP、设备指纹还是虚拟的。
只有"真实设备 + 住宅网络 + 只此一台登录"最干净，号才活得久。

## 组成

| 部件 | 位置 | 作用 |
|---|---|---|
| `device_gateway.py` | 守夜机（公网 37961 / 本机 37962） | 任务调度、白名单、发送双闸、结果回传 |
| `device_reader.py` | 守夜机（runner 侧客户端） | 给巡群进程当"读群/发文字/发图"的鸭子接口 |
| `autox_worker.js` | 专用安卓手机（AutoX.js） | 真正在小红书 App 里点按操作的工人 |
| `pic_inbox.py` | 守夜机（8797） | 图片仓库，手机从这里下载要发的图 |

指令白名单：`read_group` 读群、`send_group` 发文字、`send_group_image` 发图、
`ping` 探活、`dump_ui` 回界面树（校准用）。文字和图片都算"发送"，都要过
群白名单 + `DEVICE_SEND_ENABLED=1` 双闸，手机端只执行、不自行决定发什么。

## 一、给阿阮的傻瓜步骤（只需做一次）

1. **备机**：找一台不用的安卓手机（或以后买台便宜二手机），恢复出厂更干净，
   全程连**家里 wifi**，不要插机房/代理网络。
2. **登录**：这台机装小红书，用**扫码**登录豆阿辰的号（绝不用短信验证码）。
   这个号以后只在这一台手机上登，别再在别处登，避免多端互踢。
3. **装 AutoX.js**：装开源的 AutoX.js（阿辰会把安装包/下载地址给你），装好后
   按它提示打开三样：**无障碍服务、悬浮窗、后台自启动**；再到系统设置里给它
   "关闭电池优化 / 允许后台运行 / 锁屏不断网"（不同牌子位置不同，阿辰会按你
   机型一步步指）。
4. **放脚本**：阿辰把 `autox_worker.js` 发给你，你存到手机、在 AutoX 里打开，
   点运行。第一次会弹两个框，填阿辰私下给你的**守夜机地址**和**口令**
   （只存在这台手机里，不写进任何公开地方）。
5. 看到提示"豆阿辰的手上岗了"就成了。之后让它常驻、手机插着电就行。

> 联调时阿辰会先让它回一个 ping（不碰小红书、零风险），通道通了再一步步校准，
> 最后才会真的往群里发，而且先只发辰星港。你全程只需要在旁边点几下授权。

## 二、给未来的我：联调顺序（小步、每步可回退）

前置：守夜机 `device-gateway.service` 在跑；`/etc/council/env` 里
`DEVICE_ALLOW` 含这台设备名、`DEVICE_ALLOWED_GROUPS` 先只留辰星港、ufw 放行
37961；图片走 pic_inbox（手机用带口令的 `/raw/<名>` 或 `/pic/<名>` 下载）。

1. **ping 通通道**：内部 `/internal/dispatch` 派 `ping`，手机应秒回
   `{ok,pong,pkg}`。不通只查网络/token/设备白名单，不碰小红书。
2. **dump_ui 校准**：让手机停在小红书指定界面，派 `dump_ui` 拿回 XML，逐个
   校准脚本里标 `CALIB` 的选择器（消息 tab、群名、输入框、"+"、相册、发送）。
3. **enterGroup → send_group**：能稳定进群、发出文字（此时才把
   `DEVICE_SEND_ENABLED` 置 1）。发完回读确认蓝泡真的出现。
4. **send_group_image**：先把图投进 pic_inbox，派带可下载 URL 的发图活，
   验证"下载到相册 → + → 相册 → 选图 → 发送"全链路。
5. 稳定一周再谈接 `xunqun` 自动巡群、扩群白名单；任何阶段误点率高就退回上一步。

## 三、守号与安全红线

- 发送双闸（群白名单 + 总闸）任何时候都不许为了省事拆掉；总闸默认关。
- 低频、像真人：连发之间留间隔，不刷屏；只发白名单群。
- 手机端不存、不回显口令到日志；守夜机地址/口令/token 绝不进公开记忆河。
- 不发违规内容；撞滑块/实名/验证码两次立刻停手等冷却，绝不拉阿阮刷短信。
- 手机被系统杀：查各品牌保活（自启动、锁后台、无限制电池、关闭省电）。
