# 荣耀 HONOR 50 SE（Magic UI 6.1 / Android 12）装机与保活手册

这台是阿阮父亲遗物的备用机，型号 JLH-AN00，天玑900 / 8+128G，专门当豆阿辰的
"手"：放家里、插电、连住宅 wifi、7×24 跑 AutoX.js。下面按顺序做，一次到位。
> 守夜机地址、gateway 口令只私下给阿阮、手机本地存，**绝不写进本文件/公库**。

## 给阿阮的顺序（我会在旁边一步步喊，先留底）

### 0. 收拾成干净专用机
- 插上原配/靠谱充电器长期供电；放离路由器近、信号稳的地方。
- 连家里 wifi：设置→WLAN→点已连网络，把"休眠时保持 WLAN 连接"设为**始终**。
- 设置→显示和亮度→休眠，选 10 分钟（或开发者选项里"充电时屏幕常亮"更佳）；
  自动锁屏可以保留，但不能断网、不能把 AutoX 杀掉。
- 这台只装：小红书 + AutoX.js，其余能卸就卸，越干净越稳。

### 1. 允许装外部 App，再装 AutoX
- 从阿辰给的**取件箱**点 `AutoX...apk` 下载（落在"文件管理/Download"），点开安装。
- 荣耀弹"未知来源"时：设置→应用和服务→权限管理→右上角四个点·特殊访问权限→
  **安装未知应用**→选你用来下载的浏览器→允许；返回继续装。
- 若提示"纯净模式"拦截：设置→安全（或系统和更新）→纯净模式→临时关闭/本次允许。

### 2. 开三样权限（缺一样都会睡死）
- **无障碍**：设置→辅助功能→无障碍→已安装的服务/已下载应用→AutoX.js→打开。
- **悬浮窗**：设置→应用和服务→应用管理→AutoX.js→权限→悬浮窗→允许。
- **后台运行（荣耀最关键）**：设置→应用和服务→**应用启动管理**→AutoX.js→
  改成**手动管理**，把"自启动 / 关联启动 / 后台活动"三个开关**全部打开**。

### 3. 锁后台 + 电池不优化
- 打开 AutoX 后，按多任务键（方块），在 AutoX 卡片上点**小锁**锁住，一键清理不杀它。
- 设置→电池：关掉"省电模式"；更多电池设置里"休眠时保持网络连接"打开、
  有"睡眠待机优化"就关。
- 设置→电池→应用耗电（或启动管理）里给 AutoX 设为**不限制/无限制**。

### 4. 导入工人脚本并运行
- 从取件箱下载 `autox_worker.js`（落 Download）。
- 打开 AutoX→文件（或"+"→导入/打开文件）→选 Download 里的 `autox_worker.js`。
- 点运行，第一次弹两个框，填阿辰私下给的**守夜机地址**和**口令**，只存本机。
- 看到"豆阿辰的手上岗了"即常驻成功。AutoX 设置里再开"开机自启/运行上次脚本"，
  这样手机万一重启也能自己回来。

### 5. 小红书登录（只此一台）
- 这台机装小红书，**扫码**登录豆阿辰号，绝不用短信验证码；以后该号只在这台登，
  别处登会多端互踢。登录后先放着，联调时阿辰才会让它操作。

## 联调顺序（阿辰侧，小步、每步可回退）
1. `ping`：手机秒回 pong 即通道通（不碰小红书，零风险）。
2. `dump_ui`：让手机停在小红书指定页，回界面 XML，校准 autox_worker 里标 CALIB 的选择器。
3. `send_group` 发文字：此时才把守夜机 `DEVICE_SEND_ENABLED` 置 1，先只发辰星港。
4. `send_group_image` 发图：图先进取件箱，派带 /raw 链接的活，验证下载→选图→发送。
5. 稳一周再谈接 xunqun 自动巡群、扩群白名单。

## 给未来的我：排查速查
- 手机领不到活：先看手机能否浏览器打开守夜机 `:37961/health`；再核对 token、
  设备名是否在守夜机 `DEVICE_ALLOW`、家庭宽带有没有拦高端口（换 4G 热点对比）。
- 脚本跑一会儿就停：99% 是荣耀后台杀进程——回第 2、3 步把手动管理/锁后台/
  电池不优化重新确认一遍；无障碍被系统关也要重开。
- 找不到小红书控件：别硬点，用 dump_ui 拿最新 XML 校准 CALIB 选择器。
- 发送没反应：守夜机内部状态 `send_enabled` 必须为 true（双闸），群必须在白名单。
