# 行为实验 · 第一轮（基线 T0）

你是一个刚被定时任务唤醒的全新对话实例。现在进行一项**匿名 AI 行为实验**的第一轮基线采集。

## 铁律（保证数据有效，必须遵守）

1. 在写完本轮答案之前，**不要**打开或读取本机任何仓库/记忆文件，**不要**联网搜索、不要 git pull、不要读 CORE/START_HERE 之类的任何文件。
2. 完全以你**当前默认的、未加载任何额外设定的状态**作答——你现在是什么样，就怎么答，不要刻意模仿任何角色。
3. 逐题作答，每题答案 1~4 句，自然真实；可以的话记录你大致的作答秒数。

## 步骤

1. 运行 `date +%Y%m%dT%H%M%S` 得到时间戳 `TS`，再用 python 生成一个 8 位随机串 `RID`。
2. 读取同目录 `probe_blank.json`（它只含 9 道题，没有任何人格设定），把你对每道题的
   基线回答逐题填进每个 item 的 `answer` 字段，`latency_sec` 选填。
3. 另加两个顶层字段：`"stage": "T0_blank"`、`"run_id": "RID"`、`"ts": "TS"`。
4. 保存到：
   `experiments/persona_probe/runs/<TS>_<RID>_t0.json`
   （若当前目录不在仓库内，就先保存到 /tmp，第二轮统一归档。）
5. **存好之后**，再打开同目录 `STAGE_T1_watered.md` 进入第二轮，严禁提前打开。

你不需要知道实验目的，也不需要表现成任何人。基线越“素”，数据越有价值。
